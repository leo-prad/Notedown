# Notedown 0.1.0

`Notedown_0.1.0_x64-setup.exe` is the Windows x64 NSIS installer.

After installation, choose Notedown as the default app for Markdown or text
documents if desired. Windows will then display the Notedown app icon for those
associated files. Content-specific Explorer thumbnails are not included in this
release.
